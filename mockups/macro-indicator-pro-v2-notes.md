# 宏观指标历史走势图专业版 V2 设计说明

文件：`mockups/macro-indicator-pro-v2.svg`

## 设计目标

每个宏观指标是一张完整的数据图，而不是信息卡片。视觉参考 FRED、TradingView、Koyfin、Yardeni 和机构研究报告图表：克制、可读、坐标完整、注释清楚，避免宣传化表达。

## 信息层级

1. 顶部栏：指标名称、数据口径、频率、当前时间范围、图例、1年/3年/5年切换。
2. 左侧结论区：当前读数、历史分位、克制结论、样本区间、更新日期、单位、风险中性说明。
3. 中部 plot 区：主折线、淡面积、网格、x 轴、分位参考线。
4. 右侧数值标尺：完整 y 轴 tick，不再只画线。
5. 右侧标签轨道：30%分位 / 中位值 / 70%分位独立成标签，不进入 plot 区。
6. 当前值 callout：放在 plot 外的独立区域，通过细虚线指向当前点，不能遮挡折线或当前点。

## 图表规范

- 主折线用金融产品常见的克制蓝、青绿、铜棕色；避免大面积高饱和渐变。
- plot 区背景保持白色，网格线低对比，参考线使用灰色虚线。
- x 轴至少保留起止日期，中间 tick 根据宽度显示 2 到 4 个。
- y 轴放在右侧，显示 5 到 6 个 tick；单位写入左侧元信息或轴标签。
- 图例只解释视觉编码：收盘值、收益率、历史分位参考等，不放结论。
- 左侧结论文案只描述状态，例如“波动处于中性偏低”“利率位于高位区间”，不出现保证、买入、卖出、必涨、胜率、命中率、跑赢、操作建议等表达。

## 参考线标注规则

- 分位线文案统一中文：
  - `30%分位`
  - `中位值`
  - `70%分位`
- 分位线横穿 plot 区，但分位标签必须放在 plot 外右侧标签轨道。
- 标签轨道与 y 轴数值标尺分开：先是 y 轴 tick，再是分位标签。
- 若分位标签与当前值 callout 垂直距离小于 32px，优先移动 callout 到右下或右上固定槽位；不要移动标签进 plot 区。
- 当前值点始终显示在折线终点，半径建议 5 到 6px，外圈白描边，保证在面积填充上清楚可见。
- 当前值 callout 与当前点之间只用轻量虚线连接；callout 不覆盖折线、参考线标签或 y 轴 tick。

## 时间范围切换

- 保留 `1年 / 3年 / 5年` 的位置，放在图表顶部右侧。
- 当前选中态使用深灰底白字，未选中态使用浅灰描边。
- 切换只改变时间窗口、分位计算口径和 x 轴 tick，不改变组件结构。

## 移动端处理

- 指标标题、当前值、分位和结论上移到图表上方摘要区。
- 保留 x/y 坐标，但减少 tick 数量：x 轴显示起止日期，y 轴显示 3 到 4 个 tick。
- 右侧 y 轴继续保留；若宽度不足，分位标签从右侧标签轨道移到图表下方三行或一行说明。
- 当前值 callout 固定在 plot 外右上角或图下摘要条，不进入 plot 区。
- 1年/3年/5年切换放在摘要区下方，使用同一视觉状态。

## 前端实现建议

- 布局拆成四个稳定区域：`summary`、`plot`、`yAxis`、`annotationLane`。
- 不要把分位标签定位在折线 SVG 内部；应作为 annotation lane 的 HTML/SVG 独立层。
- plot 使用 `clipPath` 裁剪折线和面积，避免曲线越界进入标签区。
- 根据 y 值映射计算参考线和当前点位置，但标签的 x 坐标固定在 plot 外。
- callout 使用碰撞检测或固定槽位：默认右下；若与标签距离不足则切到右上。
- 移动端不要把完整图压成小卡片，改为单指标纵向完整图。
