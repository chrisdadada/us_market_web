# 产品文档

更新时间：2026-08-06
适用范围：懂币猫前台主站、后台管理、会员权限、内容与市场数据页面。

本文是产品改动的依据。和 `AGENTS.md` 冲突时，以用户当次明确确认和 `AGENTS.md` 为准。

## 1. 产品定位

懂币猫是面向中文美股用户的投资信息产品。

前台给普通用户使用，目标是帮助用户快速看到：

- 今日市场主线。
- 强势股票跟踪。
- 美股行情筛选与详情。
- 重点财经前瞻与事件。
- 市场资金走向状态。
- 有权限时查看更完整的观点、数据或工具。

后台给管理员使用，目标是管理：

- 用户与会员。
- 美股热点风向标内容。
- 实战课程内容与授权。
- 用户操作记录。
- 用户数据监控。

后台能力不得混入普通用户前台。

## 2. 已确认前台导航

前台主导航顺序：

- 首页
- 美股热点风向标
- 重点财经前瞻
- 机会跟踪榜单
- 美股行情
- 市场资金走向
- 市场活跃指数
- 行业板块强弱
- 实战课程

已确认边界：

- `Open 持仓参考`、`论坛讨论区`按未正式开放或权限状态放在次级导航。

新增、隐藏、置灰、改名导航，必须先确认。

## 3. 页面职责

首页：

- 负责当天路径和重点入口。
- 不做后台总览。
- 不重复铺满所有栏目内容。

美股热点风向标：

- 列表页负责扫描、筛选、进入详情。
- 详情页负责阅读。
- 权限不足时只遮正文或核心内容，不破坏页面结构。

机会跟踪榜单：

- 负责股票扫描、排名、对比。
- 数值密度要高，适合快速扫表。

美股行情：

- 负责查询、筛选、排序、进入个股详情。
- 数据以 API / DB 返回为准，不在前端拼假结论。

重点财经前瞻：

- 负责事件列表、日期筛选和关键事件查看。
- 公司财报和宏观事件分开表达。

市场资金走向：

- 负责板块、资金、涨跌和热力图等市场状态。
- 使用成熟金融终端式信息密度，少解释，多表格和数值。

市场活跃指数：

- 负责展示市场环境分数和相关指标走势。

行业板块强弱：

- 负责比较行业板块强弱并筛选代表股票。

后台首页：

- 负责管理概览。
- 可展示注册用户、付费用户、活跃用户、导航点击、留存。

后台用户与会员：

- 负责查看用户、调整会员、查看操作记录。
- 用户自己注册，后台默认不创建普通用户，除非业务重新确认。

后台内容：

- 负责美股热点风向标、实战课程等后台内容管理。
- 不进入普通用户前台页面。

## 4. 会员与权限

会员权限是访问控制，不是内容模块。

标准做法：

- 用户点击无权限内容时，用轻量遮罩、预览或联系开通承接。
- 未登录用户点击前台交互入口时，先提示注册 / 登录。
- 不在普通内容页硬塞“会员模块”。
- 不把权限提示做成突兀的大锁贴片。

权限相关显示必须来自后端登录状态和接口返回，不得前端臆造。

## 5. 数据边界

只展示现有 DB / API 能支撑的数据。

禁止：

- 编造统计数字。
- 推断趋势结论后当成真实数据。
- 用占位假数据冒充真实结果。
- 在 C 端展示字段来源、接口状态、数据完整度、待补字段等内部信息。

数据缺失时：

- 优先隐藏对应模块。
- 或降低展示层级。
- 不在前台主体写“暂无字段 / 待接入 / 接口来源”。

## 6. 前台文案标准

前台文案面向 C 端用户，不写成开发说明。

标准：

- 标题短，直接表达用户要看的内容。
- 同一含义不重复出现。
- 能用表格、按钮、数字表达的，不额外写解释。
- 时间统一 `YYYY-MM-DD HH:mm:ss`，24 小时制。
- 涨跌、金额、会员状态使用统一格式。
- 用中国散户能理解的人话，不滥用缩写。

## 7. UI 设计标准

所有页面开做前先出高保真图，确认后再实现。

前台整体方向：

- 白版风格。
- 浅灰底、白色面板、系统字体、清晰表格、轻阴影、蓝色主色。
- 信息密度克制，避免大标题、大留白、低信息量卡片堆叠。
- 金融数据页优先成熟终端式结构。
- 内容阅读页优先成熟内容产品结构。

后台方向：

- 清爽、专业、易管理。
- 表格、筛选、状态、操作路径清楚。
- 不做营销式视觉。

自检：

- 前后台是否混用。
- 是否展示了内部信息。
- 是否有无依据数据。
- 是否重复表达。
- 是否符合已确认导航。
- 是否只换皮肤，没有改善用户路径。

## 8. 用户数据监控口径

当前已接入口径：

- 已登录用户发生第一次页面点击，可视为当天登录。
- 3 日 / 7 日 / 30 日活跃按登录用户点击记录统计。
- 导航点击率按已登录用户导航点击统计。
- 游客点击不计入用户监控。
- 留存按注册日期分组，统计注册后 3 / 7 / 30 日内是否有点击行为。

这套口径用于后台用户监控，不等同于全站流量分析。

## 9. 未确认项

以下内容未确认前不得作为正式产品能力上线：

- 论坛讨论区正式开放方式。
- Open 持仓参考的完整权限和展示规则。
- 更复杂的 BI 漏斗、渠道归因、广告统计。
- 实时行情、实时期权链、实时期货行情。
