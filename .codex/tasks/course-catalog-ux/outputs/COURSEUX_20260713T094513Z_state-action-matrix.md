# 课程三页状态与主动作矩阵

证据边界：2026-07-13 09:45:13 UTC

## 字段语义

| 字段 | 已确认含义 | 不得推断 |
|---|---|---|
| `unlocked` | 当前用户是否可以进入课程学习页 | 不等同于会员类型、支付状态或购买记录 |
| `grantExpiresAt` | 当前课程授权到期时间；空值表示接口未提供到期时间 | 不推断永久购买、会员到期或续费状态 |
| `progressStatus` | 课程内容处于“更新中”或“已完结” | 不是用户学习进度 |
| `lessonCount` / `lessons` | 当前可展示的课时数量和目录 | 不推断用户已学课时或完成比例 |
| `discountPrice` | 当前展示价格；允许为空 | 不推断币种以外的支付方式 |
| `originalPrice` | 原价；允许为空 | 当前价为空时不能只显示划线原价 |
| `discountLabel` | 已配置的折扣短文案；允许为空 | 不生成倒计时、优惠原因或自动续期文案 |
| `summary` / `intro` | 列表摘要与详情介绍 | 不扩写课程承诺、收益或适用人群结论 |

## 页面状态

| 页面 | 条件 | 首屏信息 | 唯一主动作 | 次要信息 | 禁止表达 |
|---|---|---|---|---|---|
| 课程列表 | `unlocked=true` 且有课时 | 封面、标题、短摘要、课时数、更新状态、授权到期 | 进入课程 | 无到期时间时仅显示“已授权” | 继续学习、学习进度、已学比例 |
| 课程列表 | `unlocked=true` 且无课时 | 封面、标题、短摘要、课程状态、授权状态 | 查看课程 | “即将上线”来自零课时状态 | 播放、继续学习 |
| 课程列表 | `unlocked=false` 且有课时 | 封面、标题、短摘要、课时数、更新状态、有效价格信息、轻量权限标识 | 查看详情 | 原价和折扣仅在字段齐全时辅助当前价 | 立即购买、会员专享、续费 |
| 课程列表 | `unlocked=false` 且无课时 | 封面、标题、短摘要、即将上线；价格按真实字段决定是否显示 | 查看详情 | 不以价格替代上线状态 | 开始学习、播放 |
| 未授权详情 | `unlocked=false` | 封面、标题、课时/更新状态、摘要、课程介绍、可公开目录、有效价格信息 | 联系开通 | 权限提示只解释当前不可学习 | 支付入口、虚构购买路径、大面积锁遮罩 |
| 已授权学习页 | `unlocked=true` 且有课时 | 当前课程、当前课时、播放器、完整目录、授权到期 | 播放所选课时 | 课程更新状态放在目录头部 | 价格、折扣、联系开通、学习完成度 |
| 已授权学习页 | `unlocked=true` 且无课时 | 课程标题、授权状态、课程介绍、即将上线 | 返回课程 | 不展示空播放器 | 播放、继续学习、完成进度 |

## 价格规则

| 字段组合 | 展示规则 |
|---|---|
| 当前价 + 原价 + 折扣文案 | 当前价为主；原价和折扣为轻量辅助 |
| 当前价 + 原价 | 当前价为主；原价为轻量辅助 |
| 当前价 + 折扣文案 | 当前价为主；折扣为轻量辅助 |
| 只有当前价 | 只显示当前价，不补说明 |
| 只有原价 | 按普通价格显示，不使用划线样式 |
| 只有折扣文案 | 不单独显示，避免没有价格依据的促销表达 |
| 全部为空 | 隐藏价格区域，保持卡片动作位置稳定 |

## 页面切换

- 同时存在已授权和未授权课程：显示“我的课程 / 更多课程”两个互斥视图。
- 只有已授权课程：不制造空的“更多课程”页。
- 只有未授权课程：不制造空的“我的课程”页。
- 两类都为空：只显示统一空状态，不显示无效标签。
- 从列表进入详情后，返回应回到原视图和原滚动语境；现有代码尚未冻结滚动恢复能力，高保真图不得假装已支持。

## 状态反馈

- 加载：保持课程卡片稳定尺寸，不用大段解释。
- 加载失败：短错误信息和一个“重新加载”动作。
- 空状态：只表达“暂无课程”，不解释内部数据原因。
- 图片缺失：使用稳定比例的中性占位，不生成课程封面内容。
- 播放失败：在学习页就地提示并允许重新尝试，不跳转到开通流程。
